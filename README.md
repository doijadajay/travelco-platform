# TravelCo Platform

TravelCo is a practical microservices project demonstrating
GitOps-based feature flag management using Flipt v2.

## Technology Stack

- Flipt v2
- Python FastAPI
- Docker
- Kubernetes / Minikube
- GitHub
- GitHub Actions
- Argo CD

## Environments

| Git Branch | Environment |
|---|---|
| develop | Development |
| staging | Staging |
| main | Production |

## Microservices

- Hotel Service
- Booking Service
- Payment Service

## Feature Flags

- hotel-discount
- instant-booking
- new-payment-flow
- new-travel-ui
